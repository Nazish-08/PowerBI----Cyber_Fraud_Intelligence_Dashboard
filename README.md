# 🚨 Cyber Crime & Digital Fraud Intelligence Dashboard

An interactive Power BI dashboard designed to analyze cybercrime and digital fraud data, explore fraud patterns, monitor key indicators, and present insights through data visualizations.

## 📌 Project Overview

The **Cyber Crime & Digital Fraud Intelligence Dashboard** focuses on analyzing fraud-related data and presenting meaningful insights through interactive visualizations.

The project uses Power BI and supporting datasets to organize fraud information, explore trends, and provide a visual understanding of digital fraud activities.

## 🎯 Project Objectives

- Analyze digital fraud and cybercrime-related data.
- Present important fraud indicators through KPI visualizations.
- Explore fraud patterns using charts and graphs.
- Analyze geographical information through map-based visualizations.
- Create an interactive dashboard for data exploration and reporting.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Power BI | Dashboard development and visualization |
| CSV | Fraud-related datasets |
| Excel | Supporting data tables |
| GeoJSON | Geographical data |
| Data Visualization | Fraud analysis and reporting |

## 📁 Dataset Information

The project contains the following supporting datasets:

- **Fact Fraud Table.csv:** Fraud-related fact data.
- **creditcard.csv:** Credit card transaction dataset.
- **Dim City Geolocation.xlsx:** City geographical information.
- **State Population Table.csv:** State population information.
- **india.geojson:** Geographical boundary data for India.

4. Update data source paths if required.
5. Refresh the data to load the datasets.
6. Explore the dashboard and its visualizations.
